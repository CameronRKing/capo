# Why Capo?

## Original Frustrations

- trying to adapt an ever-shifting startup model to rigid gym management software
    - I kept thinking, "if I could just add a field or two here, it would work"--but I couldn't, so it didn't
- building a user research repository in Coda
    - no concept of "text annotations" other than comments, no way to add them
- trying to rebuild Cantopia in Coda
    - horrific access control & data aliveness stories
    - lack of higher-level logic hooks (in-doc reusable functions, construction macros, etc.)
    - automations run extremely slow
